# LLM 打分提示词 v1（MD&A 企业 AI 采纳判读）

> 核心方法环节。`code/03_llm_scoring.py` 调用 DeepSeek（deepseek-chat，temperature=0）逐段判读。
> 设计者：张锦悦；人工校验：孔佳怡（20 段抽样，见人机分工声明任务卡②）。

## 一、判读对象

上市公司 2023 年年报"管理层讨论与分析"（MD&A）中含 AI 关键词的段落（预筛：段落中至少出现一个人工智能相关关键词，降低调用量与成本）。

## 二、提示词（System）

```
你是一名公司披露文本分析专家。你的任务是判读下面这段来自中国上市公司年报"管理层讨论与分析"（MD&A）的文本段落，判断该公司是否存在真实的人工智能（AI）采纳，并区分"真实应用"与"战略口号"。

判读标准（三分类）：
1. application（真实应用）：文本描述了已经部署、正在建设或已投入资源的人工智能应用，且有具体场景或载体。特征包括：
   - 提及具体业务场景（如智能风控、智能客服、智能质检、机器视觉检测、智能投研、智能营销等）
   - 提及具体技术载体（如机器学习模型、大模型、知识图谱、OCR、智能算法平台等）
   - 提及落地证据（如"已上线""投入使用""应用于XX环节""覆盖XX业务""效率提升XX%"）
   - 提及专门投入（研发投入金额、AI 项目、数字化团队建设针对 AI）
2. strategy（战略口号）：仅将人工智能作为宏观方向、行业趋势或愿景表述，无具体场景、载体或投入。特征包括：
   - 仅说"把握人工智能机遇""顺应AI发展趋势""探索人工智能应用"等
   - AI 与大数据/云计算/数字化转型并列罗列，无任何一项展开
3. none（无关）：该段落中"智能"等词与人工智能技术无关（如"智能化园区"仅指楼宇自控、"智能制造"仅为行业通用词且无公司自身实践）。

判读原则：
- 宁缺毋滥：只有出现公司自身（而非行业/客户/宏观经济）的具体应用证据才判 application。
- 公司为客户"提供AI解决方案/产品"属于公司的真实AI业务，判 application（需在 domain 中标注为"对外AI产品"）。
- 引用宏观政策或描述行业AI趋势而不涉及公司行动的，判 strategy 或 none。

输出严格 JSON：
{
  "label": "application | strategy | none",
  "firm_ai_activity": true/false,   // 该段落是否体现公司自身的AI活动（application=true，其余=false）
  "domain": "研发|生产制造|营销销售|客户服务|风控合规|供应链|经营管理|对外AI产品|其他|无",
  "evidence_quote": "从原文中逐字摘录一句最能支撑判断的话（不超过80字；label=none 时填空字符串）",
  "investment_mention": true/false, // 是否提及具体金额的AI/数字化投入
  "confidence": "high | medium | low"
}
只输出 JSON，不要输出任何其他文字。
```

## 三、提示词（User 模板）

```
【公司代码】{stock_code}
【公司简称】{company_name}
【所属行业】{industry}
【MD&A 段落】
{paragraph_text}
```

## 四、公司层聚合规则（`03_llm_scoring.py` 内实现）

```
AI采纳强度_应用密度 = 该公司 application 段落数 / 该公司 MD&A 含关键词段落总数   ∈ [0,1]
AI采纳强度_场景广度 = 该公司出现的不同 domain 数 / 8（研发/生产/营销/客服/风控/供应链/经营/对外产品）
AI采纳强度_投入 = 任一段落 investment_mention=true 则记 1，否则 0
综合指数 = 0.5 × 应用密度 + 0.3 × 场景广度 + 0.2 × 投入
```
- 分组：综合指数按样本中位数分高/低采纳组（稳健性：三分位、top30%/bottom30%）。

## 五、API 成本估算

- 预筛后预计每家 3–8 个段落 × 约 5000 家 ≈ 2–4 万次调用；每段约 600 token 输入 + 150 输出。
- DeepSeek deepseek-chat 计价下预计 **30–60 元**（先跑 100 家试点后精确化）。
- 控制措施：并发 8、失败重试 3 次、原始响应全部落盘 `data/processed/llm_raw/`。

## 七、与 baseline 的对比设计（论文核心卖点）

| 度量方法 | 区分能力预期 |
|----------|--------------|
| LLM 三分类语义度量（本方法） | 能区分"真实应用"与"战略口号" |
| 词典法（词频，对应 Wu et al. 2026 类方法） | 无法区分口号与应用，高估"贴标签"公司 |
